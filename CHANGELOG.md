# Changelog

## 1.3.0 — 2026-09-17

- Separate Routes into Personal work and Teammate work.
- Remember protected teammate routes on the device for the wallet that opened them.
- Reopen remembered team work through the existing wallet-signature gate.
- Add compact empty states, role labels, route counts, and mobile overflow protection.

## 1.2.0 — 2026-09-17

- Add an explicit Nimiq wallet connection step at the top of the landing form.
- Keep one-time signature verification separate from wallet selection.
- Let invited teammates connect, sign, and open Track without creating a plan.
- Add narrow-screen wrapping and overflow protection to the wallet identity panel.

## 1.1.1 — 2026-09-16

- Remove the Cairn donation button and optional support checkout from the app.
- Keep Nimiq wallet identity and direct teammate rewards.

## 1.1.0 — 2026-09-16

- Add direct, verified NIM rewards for teammates who complete tasks.
- Add automatic reward confirmation with receipt-safe resume behavior.
- Add revocation for public links and protected team workspaces.
- Add versioned JSON backup and restore without transferring server access.
- Add native mobile sharing and a PNG social preview.
- Expand privacy documentation and automated coverage for the new workflows.

## 1.0.0 — 2026-09-16

- Turn a rough idea into an editable PRD, visual map, user flow, build plan, and tracker.
- Add targeted AI refinements with review before apply.
- Add optional NIM support with automatic network confirmation and recovery.
- Preserve receipt replay protection and legacy credits in an atomic SQLite Durable Object.
- Add wallet-protected team Track workspaces with Viewer and Editor roles.
- Add local-first storage, public read-only sharing, Markdown export, and privacy pages.
- Add CI, production deployment automation, release checks, and contribution templates.
